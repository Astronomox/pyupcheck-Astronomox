What it actually does

🔍

Scans your code

AST-parses every .py, .pyi, and .ipynb file. Finds every import, function call, and keyword argument you use from a package.

📋

Reads the changelog

Pulls release notes from GitHub and PyPI. Parses them for removals, deprecations, and renames that could affect you.

⚡

Cross-references

Matches what you use against what changed. Reports file, line, and the exact API at risk with severity levels.

🧬

Deep mode

Downloads both versions, diffs real function signatures, catches removed parameters at the argument level. Facts, not guesses.

🛠️

Auto-fix

Rewrites your requirements.txt to the latest safe version of every dependency. Dry-run first, commit when ready.

🚀

CI-ready

Exit code 1 on breaking changes. Generates GitHub Actions workflows and pre-commit hooks with one command.

Go deeper. NEW

Normal mode parses changelogs. Deep mode downloads the actual package source code for both versions and diffs every public function signature.

It knows you pass verify=False on line 23. It knows that parameter was removed in 3.0. It flags that exact call, not just the function.

Findings from real code analysis are tagged [FACT] so you can tell them apart from changelog-based guesses.
