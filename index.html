Know before

pyupcheck scans your code, reads changelogs, and tells you exactly what will break.

$ pip install pyupcheck

Python 3.9+ / any OS
What it does

AST scanner

Parses every .py, .pyi, .ipynb file. Finds imports, calls, and keyword arguments.

Changelog parser

Pulls release notes from GitHub and PyPI. Finds removals, deprecations, renames.

Deep mode

Downloads both versions, diffs real signatures, catches removed params at kwarg level.

Auto-fix

Rewrites requirements.txt to the latest safe version. Dry-run first, commit when ready.

CI-ready

Exit code 1 on breaking changes. Generates GitHub Actions and pre-commit hooks.

requirements.txt, pyproject.toml, setup.cfg, setup.py, environment.yml
