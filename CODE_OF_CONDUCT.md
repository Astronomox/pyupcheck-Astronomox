# Code of Conduct

## Our commitment

pyupcheck is an open project. Everyone who participates — through issues, pull requests, or discussions — is expected to treat others with respect.

## What we expect

- Be direct and constructive. Disagreement is fine; contempt is not.
- Stay on topic. This is a developer tool project.
- Give credit. If you build on someone else's work or idea, say so.
- Accept feedback. Code review is about the code, not the person.

## What we do not tolerate

- Harassment, insults, or personal attacks of any kind.
- Dismissing contributions because of who the contributor is.
- Spam, self-promotion unrelated to the project, or bad-faith participation.

## Reporting

If you experience or witness behaviour that violates this code, open a GitHub issue marked `[conduct]` or contact the maintainer directly via GitHub. Reports will be handled promptly and confidentially.

## Scope

This code of conduct applies within the project repository — issues, pull requests, commit messages, and any other project spaces.
